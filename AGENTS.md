# 🧠 AI Agent Operational Guide (README for AI)

## Directory & File Index
- `bama-scraper/src/fetch.py`: Single fetch workflow. Owns HTTP session/warmup/page iteration, Jalali/relative time parsing, `clean_name`, `intended_path_for_ad`, local SQLite `code_map.db` helpers, JSON buffering/upserts, new-path-wins relocation, forbidden metadata stripping, and safe `KeyboardInterrupt` flush. Summary prints fetched/new/updated/relocated/publish-dates-filled/remaining-NULL counts.
- `bama-scraper/src/audit.py`: Single health + repair workflow replacing migration/dedup duties. Default is read-only scan + `data/outputs/audit_report.txt`; `--fix` strips legacy metadata, seeds/fixes map rows, backfills dates, relocates path mismatches, removes duplicates by map-canonical path when possible, and prunes empty dirs. `--brand-map` bootstraps candidate `brand_aliases.json` for review only.
- `bama-scraper/src/analyze.py`: Leaf-only plotting workflow. Walks `data/BAMA ADS/**/ads.json` and writes `analysis.png` beside qualifying leaves; no global CSV/TXT reports and no global plots.
- `bama-scraper/src/paths.py`: Tiny shared project/data path helper.
- `bama-scraper/data/outputs/`: Target directory for `audit_report.txt`; analysis images live beside leaf `ads.json` files.

## Key Logic References
- `analyze.py` `leaf_title()`: builds the plot title from the leaf path relative to `ADS_ROOT`.
- `analyze.py` `create_analysis_plot()`: parses minimum price/mileage/year/transmission features and writes the 2x2 `analysis.png` panel beside a leaf.
- `fetch.py` `pure_ad()`: strips forbidden legacy scraper metadata (`computed_publish_date_jalali`, `fetch_time_ts`) so `ads.json` remains pure Bama payload.
- `fetch.py` `intended_path_for_ad(ad, output_root, brand_aliases)`: the canonical `{category}/{brand}/{model}/{variant}/ads.json` path derived from an ad's current payload (after `clean_name` + brand-alias resolution). `relocate_code_to_intended(conn, output_root, code, intended)`: when a mapped code's path differs, removes the code from its old `ads.json`, repoints the map at `intended`, returns the old rel for the post-flush empty-file sweep. Fetch is self-healing — a code whose payload drifted is moved on the spot ("new path wins").
- `fetch.py` `AdFileManager.flush()`: per file, loads existing `dict[code→ad]`, overwrites the stored ad wholesale with the fresh pure payload on match, locally upserts the SQLite map row, writes sorted/indent=2/`ensure_ascii=False`, commits once.

## Pure ad structure & time-mapping contract
- `ads.json` mirrors the Bama endpoint exactly. No `computed_publish_date_jalali` / `fetch_time_ts` inside the ad — those live in `code_map.db`.
- **Canonicality invariant:** an ad's path is determined by `intended_path_for_ad(ad)`; `code_map.ad_index.file_path` only caches it. On mismatch, the ad is *relocated* to the intended path ("new path wins"). Any change to path logic (`clean_name`, segment derivation, category triggers, `brand_aliases.json`) **requires** `audit.py --fix` to reconcile the tree+map — this is what `route_conflicts.log` records during fetch.
- `brand_aliases.json` is curated/frozen (like `time_dictionary.json`); `audit.py --brand-map` only bootstraps candidates and over-groups distinct brands sharing a Persian acronym (e.g. GMC vs JMC) — review before relying on it.
- `time_dictionary.json` is frozen/curated (never mutated at runtime). Absolute Jalali `detail.time` parsed live; relative phrase → `now − delta` anchored by the map's `fetch_time_ts`; unknown phrases logged once to `unknown_times.log` and return `None`; old ads with no anchor have `publish_date_jalali = None` until a live fetch re-observes them or `audit.py --fix` can derive an absolute saved `detail.time`.

## Operational Rules for Agents
1. **Search Before Write:** Before modifying a function, grep or search the codebase to understand its dependencies. For codebase questions, run `graphify query "<question>"` first (per `~/.claude/CLAUDE.md`); `graphify update .` after code changes.
2. **Excel-First Approach:** If the user asks for a new metric or report, append it as a new column/sheet in the existing Excel report rather than creating a new `.csv`/`.txt`.
3. **YAGNI / flat scripts:** Keep the stack stdlib + `requests` + `jdatetime` + `rich` (+ analysis). No DB/ORM/FastAPI/Streamlit in this repo. Do not convert `bama-scraper/src/` into an installable package.
4. **Single writer for `code_map.db`:** Only one `fetch.py` at a time writes the index. Use `audit.py` for read/repair checks; `analyze.py` does not need the map.
5. **Documentation:** After successfully executing a user's prompt that changes the architecture, append a summary to the bottom of this file.
